This application compares the apps installed on the device with the list present on [https://www.404media.co/hackers-claim-massive-breach-of-location-data-giant-threaten-to-leak-data/] on the Google Drive file [https://docs.google.com/spreadsheets/d/1Ukgd0gIWd9gpV6bOx2pcSHsVO6yIUqbjnlM4ewjO6Cs/edit?gid=1257088277#gid=1257088277]. It then shows the list of installed apps that are also present on the list.

Just launch the app and await.
